# ADR-002: JavaScript em vez de TypeScript

Status: aceito · 2026-08-30

Projeto de estudo de um desenvolvedor júnior iniciante.

TypeScript somaria uma camada de sintaxe (interface, generic, `as`) em cima
de coisas que ainda estão sendo aprendidas. O projeto é pequeno e tem um
autor só: o erro que TypeScript pegaria aqui aparece na primeira vez que o
app roda.

Em troca, erro de digitação em nome de campo só aparece rodando o app.
